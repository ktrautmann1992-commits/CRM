# Whitepaper „Energieeinkauf 2027“ (Leitfaden für Unternehmen)

Nicht Teil des Portals. 20 Seiten A4, eigenständige Broschüre ohne Beschnitt, im Design der Imagebroschüre
(Schrift, Bilder und Beispiel-Lastgang kommen aus `druckvorlagen/broschuere`).

```bash
node druckvorlagen/whitepaper/bau.js
```

Nur eine allgemeine Fassung mit Kontakt EGC (keine Fassung je Vertriebspartner):
das Dokument soll frei weitergegeben werden und Interessenten zum kostenlosen Energiekosten-Check führen.

Zahlen 2027 (Netzentgelte, CO₂-Preis, Stromsteuer, Umlagen): Stand 10.11.2026, teils vorläufig.
Vor jeder Neuauflage an den Quellen auf Seite 20 prüfen.
